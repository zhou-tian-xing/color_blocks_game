# 色觉鉴别能力测试 · Chromatic Acuity Test

**在线试玩：<https://zhou-tian-xing.github.io/color_blocks_game/>**

一个纯前端的色觉辨别阈测量小游戏：在 N×N 的同色方块阵列里点出颜色不同的那一块，
N 从 **2×2 逐步加码到 9×9**，程序在每轮作答后用贝叶斯方法收窄对
**「你最小能分辨多小的色差」** 的估计，最后给出**中值 ΔE₀₀** 与**误差范围**。
成绩保存在你自己的浏览器里，刷新、关机都不会丢。

直接打开网页就能玩，不需要安装任何东西。想在本地跑起来改代码见文末的
[本地开发与调试](#本地开发与调试)。

## 玩法

1. 每轮出现一屏同色方块，其中**恰好一块**颜色不同，把它点出来。
2. 每轮限时 **30 秒**，超时按答错处理。
3. 阵列规模随进度自动加码：`2×2 → 3×3 → … → 9×9`，共 **21 轮**（约 3 分钟）。
4. 结束后给出中值 ΔE₀₀、68% / 90% 可信区间、逐轮阶梯图与各阵列规模的正确率。

想快点看到结果，可以在开场弹窗里选 **「快速测试（8 轮）」**，或者直接在网址后面加参数：

```
https://zhou-tian-xing.github.io/color_blocks_game/?rounds=8     # 8 轮，2×2 到 9×9 各一次
https://zhou-tian-xing.github.io/color_blocks_game/?rounds=40    # 40 轮，更精确但更久
```

`rounds` 会被限制在 4~60 之间。轮数越少，区间越宽（见下面的[精度](#精度大概是多少)）。

键盘也能操作：`Tab` 聚焦方块后用方向键移动，`Enter` / `空格` 选中。

## 测量原理

### 色差用 CIEDE2000

所有色差都是 **ΔE₀₀**（CIEDE2000），而不是早期的 ΔE₇₆ —— 后者在饱和色区严重高估人眼敏感度。
每一轮的底色、色相方向都是随机的，避免被试适应单一色相。

生成的异色方块会先沿 Lab 空间某个方向解析求解，再在 8bit 整数格点上做邻域精修，
并且**记录的是量化后真正渲染出来的那个色差**，而不是请求的目标值。

### 心理测量模型

被试在 N×N 阵列里作答，猜中的下限随阵列变大而降低，模型据此校正：

```
P(正确 | ΔE, 格数 m) = γ + (1 − γ − λ) · Φ( (ln ΔE − ln θ) / σ )
```

- `γ = 1/m`：纯猜命中的概率（2×2 是 25%，9×9 只有 1.2%）
- `λ = 0.02`：失误率，避免似然出现 0/1 导致后验退化
- `θ`：**要估计的最小可鉴别 ΔE**（检测正确率 50% 处）
- `σ`：心理测量函数在对数轴上的陡度

### 为什么不确定度会越来越小

`(θ, σ)` 是一个二维网格上的**精确贝叶斯后验**：

- 每一轮作答后按上面的似然更新 → 后验自动收窄，右侧面板能直接看到曲线变尖、色带变窄；
- 下一轮该用多大的 ΔE，取**期望后验熵最小**的那个水平（信息量最大化），
  因此收敛比固定步长的阶梯法快得多，也不依赖人工设定的升降规则。

## 结果怎么读

| 指标 | 含义 |
| --- | --- |
| **中值 ΔE₀₀** | 50% 检测正确率对应的色差，即最小可鉴别色差，**越低越好** |
| **68% / 90% 可信区间** | 误差范围。由**联合后验**算出，已把 σ 的不确定性一并计入 |
| **75% 正确率对应** | 换一个正确率口径的阈值，便于和其它测试对比 |
| **心理测量陡度 σ** | 你的判断从"全靠猜"过渡到"全对"有多快；越小说明转变越干脆 |

评级（按中值 ΔE₀₀）：`≤1.0 极佳` · `≤2.0 优秀` · `≤4.0 良好` · `≤8.0 中等` · `≤15 偏低` · `>15 需留意`。

### 精度大概是多少

用虚拟被试（已知真实阈值）各跑 120 次，实测估计器的表现：

| 轮数 | 相对偏差 | 68% 区间覆盖率 | 90% 区间覆盖率 | 平均相对不确定度 |
| --- | --- | --- | --- | --- |
| 21 轮 | −1.7% ~ +0.4% | 76–80% | 95–98% | **约 ±12%** |
| 8 轮 | −5.2% ~ −0.8% | 77–96% | 96–100% | **约 ±25%** |

也就是说：**基本无系统性偏差**，区间覆盖率略高于名义值（偏保守，不会给出过于自信的误差范围）。
完整 21 轮的误差范围大约是"真值 ±12%"，8 轮快速模式放宽到"±25%" —— 这就是"轮数越少区间越宽"的量化版本。

## 纪录是怎么保存的

用 `localStorage`（键名 `chromatic-acuity.v1`），**只存在你这台机器的这个浏览器里**，
不会上传到任何服务器，也不依赖登录。保存内容包括：

- `best`：中值 ΔE₀₀ 最低的一次（越低越好）
- `history`：最近 40 次的成绩，用于画历史走势

换机器 / 换浏览器 / 清空浏览器数据就会丢失。结果页有「清除本机纪录」按钮。

## 本地开发与调试

线上那份是纯静态站点，本地跑一份完全等价，改动不需要任何构建步骤。

### 运行

```bash
npm start          # 启动并自动打开浏览器
npm run dev        # 同上
npm run serve      # 同上
```

**零依赖**，不需要先 `npm install` —— 只用 Node 内置模块起一个静态服务器。

启动后终端会打印地址（默认 <http://localhost:5188/>，端口被占用时自动顺延）。
加 `--no-open` 可以不自动开浏览器，用 `PORT=6000` 可以指定端口：

```bash
npm start -- --no-open
PORT=6000 npm start
```

停止服务按 `Ctrl+C`。本地同样支持 `?rounds=` 参数，例如
<http://localhost:5188/?rounds=8>。

### 测试

```bash
npm test
```

不需要浏览器，直接验证纯计算部分（约 20 秒，2830+ 项断言）：

- sRGB ↔ Lab 往返一致性；
- CIEDE2000 与 Sharma et al. (2005) 公开参考数据逐条比对（33 组，误差 < 1e-4）；
- 刺激色生成：色域合法性、8bit 量化后 ΔE 与目标值的偏差；
- **虚拟被试收敛测试**：用已知阈值的模拟被试跑完整流程，检验中值估计、区间覆盖与不确定度收窄；
- 结果页 / 开场页渲染：用模拟出来的成绩渲染 `views.js`，检查数值、分阵列统计、标签配对；
- 本机纪录持久化：用一个内存版 `localStorage` 走完读写、破纪录判定、历史上限与数据损坏回退。

### 项目结构

```
server.js              零依赖静态服务器（自动选端口、自动开浏览器）
public/                站点根目录，GitHub Pages 直接发布这个文件夹
  index.html
  styles.css
  src/
    color.js           sRGB ↔ Lab、CIEDE2000、色域内刺激色生成
    psycho.js          贝叶斯后验、信息量最大的刺激选取、可信区间、阵列日程
    charts.js          Canvas 图表（后验密度、逐轮阶梯、历史走势）
    views.js           弹层 HTML 的纯函数（开场页 / 结果页 / 提示）
    store.js           localStorage 读写
    main.js            游戏流程与界面
tools/
  smoke-test.mjs       纯计算模块的自动化测试
```

### 部署

推送 `main` 分支会触发 `.github/workflows/pages.yml`，把 `public/` 整个目录发布到
GitHub Pages。应用是纯前端的，没有构建步骤，工作流只是上传静态文件。
用的是 `actions/configure-pages@v5` + `actions/deploy-pages@v4` 这套官方流程。

> 国内网络下推送可能失败（`Failed to connect to github.com:443`）。这是对 `github.com` 的
> DNS 污染，与仓库本身无关；`api.github.com` 和 `github.io` 通常仍然可访问。
> 需要挂代理或在能连通的环境里推送。

## 注意事项

- 测的是**你这块屏幕 + 这双眼睛**的综合表现。屏幕色彩空间、亮度、环境光、
  夜间模式 / 护眼模式都会改变实际呈现的颜色，换台机器数字就会变。
- 用笔记本屏幕、外接显示器、手机分别测，结果会有差异，这很正常。
- 本测试的显示下限约为 **ΔE₀₀ ≈ 0.45**：8bit 色深已经无法可靠表达更小的色差。
- 单次结果受注意力与疲劳影响，多测几次看趋势比看单次数字更有意义。
- **仅供自我参考，不能替代医学色觉检查**（如 Ishihara 假同色图、FM-100 Hue）。
  如果多次复测阈值都明显偏高，请到眼科做正规检查。
